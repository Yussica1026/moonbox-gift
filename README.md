# Moonbox Gift

Moonbox Gift is a public, source-visible web project for creating a custom mooncake gift link with a hidden letter.

## Current version

Public v4:
- static single-page site
- no account system
- no database
- user-provided recipient, signature, letter, filling, filling reason, and mold text
- full preview flow before generating a gift link
- recipient flow includes making, filling, molding, baking, eating, and revealing the hidden letter
- no preset relationship wording, preset filling choices, or built-in emotional prompt text
